# 📊 Análise de Casos de Dengue no Brasil

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver um sistema web com painéis interativos para análise de casos de dengue no Brasil. A plataforma permite a visualização e comparação de dados entre diferentes anos e estados, facilitando a identificação de tendências e padrões.

O sistema foi pensado para apresentar dados de forma clara, acessível e intuitiva, atendendo tanto especialistas quanto usuários leigos.

## 🎯 Objetivo

- Analisar dados epidemiológicos da dengue no Brasil  
- Identificar tendências de crescimento ou redução de casos  
- Comparar dados entre anos e estados  
- Apoiar a tomada de decisão baseada em dados  

---

## 🚀 Funcionalidades (MVP)

- Painel interativo de visualização de dados  
- Comparação de casos entre anos  
- Comparação entre estados brasileiros  
- Gráficos de evolução e comparação  
- Indicadores e KPIs relevantes  
- Interface simples e intuitiva  

---

## 📊 Indicadores (KPIs)

- Total de casos por ano  
- Taxa de crescimento (%)  
- Casos por estado  
- Casos por região  
- Casos por 100 mil habitantes  
- Estado com maior incidência  
- Média de casos ao longo dos anos  

---

## 🧠 Metodologia

O projeto foi desenvolvido seguindo as etapas:

1. **Coleta de Dados**  
   Dados públicos (DATASUS, Ministério da Saúde, etc.)

2. **Tratamento de Dados**  
   Limpeza e padronização dos dados

3. **Análise Exploratória (EDA)**  
   Identificação de padrões e tendências

4. **Prototipação**  
   Desenvolvimento do layout no Figma

5. **Visualização de Dados**  
   Criação de gráficos e dashboards

6. **Documentação**  
   Registro do projeto no GitHub
